# ADR 0002 — Marketplaces and free audits are the primary sales motion

**Status:** accepted · 2026-09-17

**Context.** The operator wants zero sales calls. Taskman's wedges sit inside existing money streams
(Stripe, Razorpay, Tally, SaaS contracts) whose owners already browse those platforms' marketplaces.

**Decision.** Primary motion = marketplace listing → free read-only audit with the buyer's own numbers →
one-click install → pay on verified outcome. Content/GEO and calculators feed the audit. Outbound is secondary.

**Consequences.** Marketplace review timelines and rules become roadmap dependencies. The audit must be
genuinely useful even if the buyer never installs (it's also the best demand data for Taskman).
