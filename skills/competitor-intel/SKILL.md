# Competitor intelligence

## Watch list per wedge (seed; keep in `config/competitors.json`)
- Revenue recovery: Stripe Smart Retries (platform default), Churnkey, Churn Buster, Butter, FlyCode,
  Baremetrics Recover, Paddle Retain, low-price entrants (Recurflux, ChurnWard, Triggla)
- India recurring: Razorpay Intelligent Retry Engine (platform risk), Cashfree, gateway-native tools
- Renegotiation: Vertice/Vendr, Tropic, Spendflo, SpendHound, Varisource (shared savings)
- Tally: authorised partner add-ons in similar categories

## For each competitor, record (dated, with source URLs)
pricing model and entry price · target segment · core mechanism · integrations · limits · recent changes ·
review themes (what customers complain about)

## Classify every change
- **Platform threat** — the platform ships the feature natively → re-position to what the platform won't do
  (cross-platform visibility, outcome pricing, leak types it has no incentive to surface)
- **Price move** → strategist decides; never auto-match
- **Positioning shift** → update comparison pages within a week
- **Complaint cluster** → messaging opportunity; verify we actually do better before claiming it

## Rules
- Every claim about a competitor needs a dated public source.
- Paraphrase, don't copy their copy.
- Never access competitors' products under false identity.
