# Persuasive copywriting

positioning-and-messaging decides *what* to say (the value prop, the ICP fit). This skill decides *how*
to say it so a skimming stranger keeps reading and then clicks. It never introduces a new claim —
everything here is applied to claims that already passed claims-and-compliance.

## Structure that earns the next sentence
- **Lead with the number or the pain, not the company.** "Your Stripe account is losing money to things
  retries don't fix" beats "Sellman helps SaaS companies recover revenue."
- **Tension then resolution, in that order.** Name the specific loss before the fix — a fix with no named
  loss reads as a generic pitch.
- **One CTA, stated as the next physical action** ("run the audit," "reply with your CSV"), not a vague
  "learn more."

## Mechanics that hold attention
- Specific numbers beat round numbers ("₹47,300" beats "₹47,000" beats "a significant amount") —
  specificity itself signals it's real, not marketing.
- Short sentences for the claim, longer ones for the context. Vary length; monotone sentence length
  reads as generated.
- Cut every sentence that could open a listicle. If it would work in any competitor's copy unchanged,
  it's not doing persuasive work — it's filler.

## Ethical urgency only
Urgency must point at a real, checkable fact (a window closing, a cost compounding daily) — never a
fabricated scarcity ("only 3 spots left") or countdown with no mechanism behind it. Taskman's own
DEFAULT_BANNED_PHRASES list ("guaranteed," "risk-free," "100%") is a floor, not the ceiling — this skill's
job is writing compellingly *inside* that floor, not finding ways around it.

## Test before it ships
Read the draft's first line alone, out of context. If it doesn't make the reader want the second line,
the structure is wrong, not the wording — rewrite the lead before polishing the copy under it.
