# score-the-move

Trigger: lane waiting, blocked, dead, or what else could make money.

## Rubric

Distribution weight 0.35. Fulfilment. Rail. Price. Kill if nobody says yes without a conversation, if a license is required, if money cannot land, or if only the floor is occupied.

## Output

3-5 options + one recommendation. Not a plan.
