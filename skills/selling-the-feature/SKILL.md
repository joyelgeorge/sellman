# selling-the-feature

Trigger when anyone says invite users, waitlist, growth, signups, or get people on Taskman.

## Rule

Name the feature, the buyer, the proof, the price, and the rail. If any is missing, stop. A signup is not a customer.

## Output

One offer line: feature · buyer · proof · price · rail.

## Kill

User-invite, waitlist, come try the app, referral loops, seat discounts.
